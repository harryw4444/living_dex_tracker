# 📦 Living Dex Tracker

A lightweight web application built to parse local Pokémon save files, PC banks, and individual file exports to visualize Living Pokédex progress.

## Key Features

* Reads `.pk1`–`.pk9`, `.pb8`, `.bin`, `.sav`, and `main` files entirely in your browser.
* Automatically reads box offsets, binary data, or filename prefixes to extract National Pokédex IDs.
* Includes a light/dark theme toggle, directory loader, generation filters, and real-time counter.
* Lazy-loads pixelated sprites via PokéAPI with automatic grayscale filters for missing species.
* Single-page app designed to run with minimal dependencies.
